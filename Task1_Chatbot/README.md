# Task 1 - Rule-Based Chatbot

## Objective

The objective of this project is to build a simple rule-based chatbot that responds to user inputs using predefined rules.

## Technologies Used

- Python

## Description

This chatbot is a simple console-based application developed using Python.

It uses predefined conditions to identify common user inputs and provide appropriate responses.

The chatbot can respond to greetings, questions about its name, simple help requests, and "how are you" questions.

The user can type "bye" to end the conversation.

## Features

- Greets the user
- Responds to common questions
- Provides basic help
- Uses predefined rules
- Allows the user to exit the chatbot

## How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the `Task1_Chatbot` folder.
4. Run the following command:

```bash
python chatbot.py
