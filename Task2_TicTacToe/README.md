# Task 2 - Tic-Tac-Toe AI

## Objective

To develop an AI agent that plays Tic-Tac-Toe against a human player.

## Technologies Used

- Python
- Minimax Algorithm
- Recursion
- Functions

## Description

This project allows a human player to play Tic-Tac-Toe against an AI opponent.

The human plays as X and the AI plays as O.

The AI uses the Minimax algorithm to evaluate possible moves and select its move.

## How to Run

Run the following command:

python tic_tac_toe.py
